LE BON PÉRIMÈTRE

LE CONSEIL
N’EST PAS LE CODE.

Une mission peut couvrir uniquement l’analyse et le pilotage, ou inclure des réalisations lorsque le périmètre le permet. Le rôle de chacun, les responsabilités et les livrables sont définis dans la proposition.

Premier rendez-vous gratuit, puis devis adapté à la durée et aux objectifs du projet.

QUESTIONS FRÉQUENTES

ENCORE UNE
QUESTION ?

Peut-on faire appel à YNS Studio uniquement pour du conseil ?+

Oui. Une mission peut porter sur le cadrage, les recommandations ou le pilotage, sans développement technique inclus.

Pouvez-vous concevoir une application ?+

Le studio peut intervenir sur la réflexion, la structure fonctionnelle, le parcours et la coordination. Le développement complexe est chiffré séparément selon les compétences mobilisées.

Comment est défini le prix ?+

Après le rendez-vous gratuit, le périmètre, les livrables et la durée d’intervention font l’objet d’une proposition sur mesure.
