## Ajouter des réalisations

1. Ouvre le sous-dossier du projet (ou crée un nouveau sous-dossier).
2. Utilise **Add file → Upload files** dans GitHub.
3. Ajoute les maquettes, présentations, photos, PDF ou autres sources autorisés.
4. Pour chaque projet, nous pourrons ensuite documenter : l'année, le contexte, ton rôle, les livrables, les outils, le résultat et les illustrations utilisables.

**Important :** les fichiers ZIP restent des archives. Ils ne sont pas encore des fiches de portfolio et ne seront pas automatiquement visibles sur le site.

## Confidentialité

**Le dépôt `Atemani/portfolio-younes` est PUBLIC.** Tout fichier présent ici peut être téléchargé, y compris les fichiers ZIP et les documents qu’ils contiennent. Ne dépose pas de fichiers d’entreprise confidentiels, de données clients, de ressources dont la diffusion est interdite ou d’éléments permettant d’identifier des projets que tu ne veux pas associer publiquement à ton profil.

Un dépôt **privé séparé** est préférable pour trier et analyser des documents non publics.
