# Projets à documenter pour le portfolio

Ce dossier sert à **rassembler les réalisations et pièces justificatives à sélectionner** pour une future version plus traditionnelle du portfolio (défilement chronologique, fiches projets détaillées et galerie).

> ⚠️ **ATTENTION : ce dépôt GitHub est PUBLIC.** Les fichiers ajoutés ici sont accessibles à tous sur GitHub, même s'ils ne sont pas affichés sur le site Cloudflare Pages. N'y dépose **aucun document confidentiel**, fichier interne d'entreprise, donnée client, coordonnées privées, élément sous NDA, ni contenu dont tu n'as pas le droit de partager la diffusion. Les projets et marques à garder privés doivent rester dans un dépôt GitHub **privé**, séparé.

## Comment ajouter tes projets

1. Ouvre ce dossier sur GitHub.
2. Clique sur **Add file → Upload files**.
3. Dépose uniquement les fichiers que tu peux rendre publics (captures autorisées, photographies, maquettes, PDF, etc.).
4. Pour chaque réalisation, crée si besoin un sous-dossier au nom explicite, par exemple `2023-menu-la-dolce-vita/`, `2023-pizza-and-love/` ou `2022-dynam8-prototype/`.
5. Ajoute idéalement un petit fichier de présentation dans chaque sous-dossier, avec : **année**, **contexte**, **ce que j'ai fait**, **outils**, **résultat** et **droit de publication**.

Distinguer deux expériences complémentaires :

- **Le bureau interactif :** une sélection courte, personnelle et immersive.

Ce dossier n'est **pas** destiné à être affiché tel quel dans le portfolio. Les projets seront relus, sélectionnés, contextualisés et intégrés ensuite.
